# thedevper/scoop-bucket

```powershell
scoop bucket add thedevper https://github.com/thedevper/scoop-bucket
scoop install rodu
```

| App | |
|---|---|
| [rodu](https://github.com/thedevper/rodu) | Local-first, AI-first kanban for small teams |

Manifests are generated by each project's release build; update them from the release's `rodu.json`.
Rodu was called Shoal before 0.2.0: `scoop uninstall shoal`, then `scoop install rodu`.
